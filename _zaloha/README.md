# Záloha (memory + návrhy)

Bezpečnostná kópia poznámok a návrhov k webu ALFA Taekwondo, aby sa nič nestratilo.

- `memory/` — pracovné poznámky (stav projektu, deploy postup, font gotcha).
- `navrhy/` — pôvodný návrh/dizajn webu.

> ⚠️ Ak je tento repozitár **verejný**, tieto poznámky sú verejne viditeľné.
> Ak to nechceš, presuň repo do *Private* v nastaveniach na GitHube
> (Settings → Danger Zone → Change visibility) — Pages na verejnom repe fungujú
> aj tak; pre súkromný repo treba GitHub Pro alebo iný hosting.
