Používateľ je **Lukáš**, GitHub účet **lukaskooravsky** — pod ním pushuje (od 2026-10-12 aj na tomto Windows stroji).
**DusanOravsky** je účet **otca** používateľa — nepoužívať na push ani ako autora commitov.
Komunikuje po slovensky, stručne. Web je pre trénera taekwonda používateľa, viď [[project-alfa-taekwondo-web]], push viď [[deploy-git-lukasko-token]].
