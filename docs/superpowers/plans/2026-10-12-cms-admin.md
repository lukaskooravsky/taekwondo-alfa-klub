# CMS admin (aktuality + galéria) — implementačný plán

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tréner si cez `/admin/` (heslo) sám spravuje aktuality a albumy fotiek; verejný web ich vypisuje v doterajšom dizajne.

**Architecture:** Čisté PHP bez frameworku a bez databázy. Logika je v malých súboroch `inc/*.php` (čisté funkcie, testované cez vlastný runner `tests/run.php`), dáta v `data/*.json` (atomický zápis + zálohy), fotky v `uploads/`. Verejné stránky `index.php`, `aktuality.php`, `aktualita.php`, `galeria.php` vypisujú tie isté HTML štruktúry ako dnes; admin je v `admin/`, fotky zmenšuje prehliadač (canvas → WebP) pred nahratím.

**Tech Stack:** PHP ≥ 8.1 (rozšírenia `fileinfo`, `gd`, `mbstring`), Apache `.htaccess`, vanilla JS (ES2017), existujúce `css/style.css`.

**Hosting:** Websupport (Apache + nginx proxy pred ním, PHP 8.3+ nastavené vo WebAdmine, (S)FTP, SSH len dočasne). Nič pri nasadení nesmie vyžadovať príkazový riadok na serveri.

**Spec:** `docs/superpowers/specs/2026-10-12-cms-admin-design.md`

## Global Constraints

- PHP ≥ 8.1 (kód), na Websupporte PHP 8.3+; žiadny Composer, žiadny framework, žiadna databáza.
- Každý PHP súbor začína `<?php` a `declare(strict_types=1);` (okrem šablón `inc/layout-*.php`).
- Všetky texty pre používateľa po **slovensky**; technické detaily len do `error_log`.
- Všetok text z dát sa vypisuje cez `e()` (htmlspecialchars). Žiadne `echo $premenna` bez `e()`, okrem výstupu z `text_to_html()` a `render_*()`.
- ID: `p_…` aktualita/fotka aktuality, `a_…` album, `f_…` fotka v albume; regex `^[paf]_[a-z0-9]{6,32}$` — **vždy s modifikátorom `D`** (inak `$` pustí koncové `\n`).
- Cesty k fotkám sa v JSON ukladajú **relatívne k `uploads/`** (napr. `posts/p_x.webp`); URL vytvára `upload_url()` → `uploads/posts/p_x.webp`. (Implementačný detail oproti príkladu v spec, kde je aj prefix `uploads/`; správanie rovnaké.)
- Fotky: veľká max **1600 px**, náhľad max **480 px**, WebP kvalita **0.82** (fallback JPEG); upload max **5 MB**; len JPEG/PNG/WebP.
- Prihlásenie: 1 heslo (min **10 znakov**, hash v `data/auth.json`), relácia **30 dní**, **5 chybných pokusov → 15 min blokácia** na klienta (IPv6 po /64), globálny strop **50 / 15 min**; pokus sa počíta pred overením hesla.
- Admin a `install.php` len cez HTTPS (`.htaccess` + `require_https()`), výnimka `localhost`.
- Limity textu: nadpis aktuality max 150, úvod max 300, celý text max 20 000, názov albumu max 120 znakov.
- Zálohy: posledných **20** verzií každého JSON v `data/backup/`.
- `data/`, `uploads/`, `install-token.php` nie sú v gite. Žiadny `config.php` neexistuje.
- Dizajn verejného webu sa nemení: rovnaké triedy `.posts > article.post`, `.gallery > figure`, farby/fonty z `css/style.css`.
- Commity ako `lukaskooravsky` (už nastavené v gite), správy po slovensky v štýle `feat: …`, `test: …`, `docs: …`, s riadkom `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.
- Pracuje sa na vetve `cms-admin`; `main` sa nemení.

## Review Focus

1. **Fotka, ktorú prehliadač nevie zmenšiť (HEIC z iPhonu v desktop Chrome, poškodený súbor)** → odošle sa originál a server ju odmietne slovenskou hláškou „Toto nie je fotka vo formáte JPG, PNG alebo WebP.“, nič nespadne. Test: Task 4 (`upload_check` odmietne ne-obrázok aj PHP súbor s príponou .png).
2. **Nadpis/text s HTML, úvodzovkami alebo URL** (`<script>`, `"`, `https://x.sk/?a=1&b=2`) → na webe sa zobrazí doslovne, URL je klikateľná a nič neunikne z atribútu. Testy: Task 2 (`text_to_html`) a Task 8 (`render_post_card`).
3. **Relácia vyprší počas nahrávania albumu** → každá fotka dostane hlášku „Prihlásenie vypršalo…“, nie biely JSON/HTML. Test: Task 13 krok s `curl` (401 + JSON).
4. **Zmazanie titulnej fotky / poslednej fotky albumu** → titulnou sa stane prvá fotka; prázdny album zmizne z verejnej galérie, no v admine ostane. Testy: Task 6.
5. **Poškodený alebo chýbajúci `posts.json` / `albums.json`** → verejná stránka vráti 200 s prázdnym stavom, admin hlásku a nič neprepíše. Testy: Task 3 (`store_update` neprepíše poškodený súbor) a Task 8 krok s `curl`.

```php
<?php
declare(strict_types=1);

define('ROOT', dirname(__DIR__));
date_default_timezone_set('Europe/Bratislava');
if (function_exists('mb_internal_encoding')) mb_internal_encoding('UTF-8');

require_once __DIR__ . '/site.php';

/** Prepisy ciest (len testy nastavujú $GLOBALS['CONFIG']); na hostingu platia predvolené hodnoty. */
function cfg(string $key, mixed $default = null): mixed
{
    return $GLOBALS['CONFIG'][$key] ?? $default;
}

function data_dir(): string { return cfg('data_dir', ROOT . '/data'); }
function uploads_dir(): string { return cfg('uploads_dir', ROOT . '/uploads'); }
function install_token_file(): string { return cfg('install_token_file', ROOT . '/install-token.php'); }

/** Vytvorí data/ (s ochranným .htaccess) a uploads/ — tieto priečinky nie sú v gite. */
function ensure_storage(): void
{
    $dirs = [
        data_dir() => "Require all denied\n",
        data_dir() . '/backup' => null,
        data_dir() . '/sessions' => null,
        uploads_dir() => null, // PHP v uploads/ blokuje koreňový .htaccess (Options/RemoveHandler tu môžu dať chybu 500)
        uploads_dir() . '/posts' => null,
        uploads_dir() . '/albums' => null,
    ];
    foreach ($dirs as $dir => $htaccess) {
        if (!is_dir($dir) && !mkdir($dir, 0775, true) && !is_dir($dir)) {
            throw new RuntimeException("Nepodarilo sa vytvoriť priečinok $dir");
        }
        if ($htaccess !== null && !is_file("$dir/.htaccess")) {
            file_put_contents("$dir/.htaccess", $htaccess);
        }
    }
}

/** HTTPS priamo alebo cez proxy hostingu (Websupport má pred Apache nginx). */
function request_is_https(?array $server = null): bool
{
    $s = $server ?? $_SERVER;
    if (!empty($s['HTTPS']) && strtolower((string)$s['HTTPS']) !== 'off') return true;
    return strtolower((string)($s['HTTP_X_FORWARDED_PROTO'] ?? '')) === 'https';
}

function is_local_host(?array $server = null): bool
{
    $host = (string)(($server ?? $_SERVER)['HTTP_HOST'] ?? '');
    return preg_match('/^(localhost|127\.0\.0\.1|\[::1\])(:\d+)?$/D', $host) === 1;
}

/** Admin a install len cez HTTPS (lokálny vývoj na localhost je výnimka). */
function require_https(): void
{
    if (PHP_SAPI === 'cli' || request_is_https() || is_local_host()) return;
    header('Location: https://' . $_SERVER['HTTP_HOST'] . ($_SERVER['REQUEST_URI'] ?? '/'), true, 301);
    exit;
}
```

```php
<?php
declare(strict_types=1);

function e(?string $s): string
{
    return htmlspecialchars((string)$s, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
}

/** Prostý text → HTML: prázdny riadok = nový odsek, riadok = <br>, http(s) URL = odkaz. */
function text_to_html(string $text): string
{
    $text = trim(str_replace(["\r\n", "\r"], "\n", $text));
    if ($text === '') return '';
    $out = [];
    foreach (preg_split('/\n[ \t]*\n+/', $text) as $para) {
        $html = e(trim($para));
        // URL hľadáme až v escapovanom texte; entity úvodzoviek a <> do URL nepatria

            $url = rtrim($m[0], '.,;:!?)');
            $tail = substr($m[0], strlen($url));
            return '<a href="' . $url . '" target="_blank" rel="noopener">' . $url . '</a>' . $tail;
        }, $html);
        $out[] = '<p>' . str_replace("\n", '<br>', $html) . '</p>'; // nl2br by nechal \n za <br>
    }
    return implode("\n", $out);
}
```

```php
    return is_string($id) && preg_match('/^' . $prefix . '_[a-z0-9]{6,32}$/D', $id) === 1;

    return date('c');

{
    return data_dir() . "/$name.json";

/** Prečíta zoznam z data/<name>.json. Chýbajúci súbor = [], poškodený = StoreException (volatile: []). */
function store_read(string $name, string $rootKey, bool $volatile = false): array
{
    $file = store_path($name);
    if (!is_file($file)) return [];
    $data = json_decode((string)file_get_contents($file), true);
    if (!is_array($data) || !is_array($data[$rootKey] ?? null)) {
        if ($volatile) return [];
        throw new StoreException("Súbor $name.json je poškodený.");
    }
    return $data[$rootKey];
}

/**
 * Bezpečná úprava dát: zámok → načítanie → $fn(&$items) → záloha + atomický zápis.
 * Ak $fn vyhodí výnimku, nič sa nezapíše. Vráti návratovú hodnotu $fn.
 */
function store_update(string $name, string $rootKey, callable $fn, bool $volatile = false): mixed
{
    ensure_storage();
    $lock = fopen(data_dir() . '/.lock', 'c');
    if ($lock === false || !flock($lock, LOCK_EX)) {
        throw new StoreException('Nepodarilo sa zamknúť dáta.');
    }
    try {
        $items = store_read($name, $rootKey, $volatile);
        $result = $fn($items);
        store_write_locked($name, [$rootKey => $items], !$volatile);
        return $result;
    } finally {
        flock($lock, LOCK_UN);
        fclose($lock);
    }
}

function store_write_locked(string $name, array $data, bool $backup = true): void
{
    $file = store_path($name);
    if ($backup && is_file($file)) store_backup($name);
    $json = json_encode($data, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES | JSON_THROW_ON_ERROR);
    $tmp = $file . '.tmp-' . bin2hex(random_bytes(4));
    if (file_put_contents($tmp, $json) === false || !rename($tmp, $file)) {
        @unlink($tmp);
        throw new StoreException("Nepodarilo sa uložiť $name.json.");
    }
}

function store_backup(string $name): void
{
    $dir = data_dir() . '/backup';
    copy(store_path($name), sprintf('%s/%s-%s-%s.json', $dir, $name, date('Ymd-His'), bin2hex(random_bytes(3))));
    $files = glob("$dir/$name-*.json") ?: [];
    usort($files, fn(string $a, string $b): int => filemtime($a) <=> filemtime($b) ?: strcmp($a, $b));
    foreach (array_slice($files, 0, max(0, count($files) - BACKUP_KEEP)) as $old) {
        unlink($old);
    }
}
```

```php
<?php
declare(strict_types=1);

final class UploadException extends RuntimeException {}

const UPLOAD_MAX_BYTES = 5 * 1024 * 1024;
const UPLOAD_TYPES = ['image/jpeg' => 'jpg', 'image/png' => 'png', 'image/webp' => 'webp'];
const IMAGE_FULL_MAX = 1600;
const IMAGE_THUMB_MAX = 480;
const GD_MAX_PIXELS = 25_000_000;
// modifikátor D: $ nepustí koncové \n
const UPLOAD_SUBDIR_RE = '~^(posts|albums/a_[a-z0-9]{6,32})$~D';
const UPLOAD_BASE_RE = '~^[pf]_[a-z0-9]{6,32}$~D';
const UPLOAD_REL_RE = '~^(posts|albums/a_[a-z0-9]{6,32})/[pf]_[a-z0-9]{6,32}(_t)?\.(jpg|png|webp)$~D';

/** Overí záznam z $_FILES; vráti príponu podľa skutočného obsahu súboru. */
function upload_check(array $file): string
{
    $err = $file['error'] ?? UPLOAD_ERR_NO_FILE;
    if ($err === UPLOAD_ERR_INI_SIZE) throw new UploadException('Fotka je príliš veľká pre server (limit ' . ini_get('upload_max_filesize') . ').');
    if ($err === UPLOAD_ERR_FORM_SIZE) throw new UploadException('Fotka je príliš veľká (max 5 MB).');
    if ($err === UPLOAD_ERR_NO_FILE) throw new UploadException('Nevybral si žiadnu fotku.');
    if ($err !== UPLOAD_ERR_OK) throw new UploadException('Fotku sa nepodarilo nahrať, skús znova.');
    $path = (string)($file['tmp_name'] ?? '');
    if (!is_file($path)) throw new UploadException('Fotku sa nepodarilo nahrať, skús znova.');
    if (($file['size'] ?? 0) > UPLOAD_MAX_BYTES || filesize($path) > UPLOAD_MAX_BYTES) {
        throw new UploadException('Fotka je príliš veľká (max 5 MB).');
    }
    $mime = (string)(new finfo(FILEINFO_MIME_TYPE))->file($path);
    $info = @getimagesize($path);
    if (!isset(UPLOAD_TYPES[$mime]) || $info === false || $info['mime'] !== $mime) {
        throw new UploadException('Toto nie je fotka vo formáte JPG, PNG alebo WebP.');
    }
    return UPLOAD_TYPES[$mime];
}

function upload_path(string $rel): string { return uploads_dir() . '/' . $rel; }
function upload_url(string $rel): string { return 'uploads/' . $rel; }

/**
 * Uloží fotku ako uploads/<subdir>/<base>.<ext> a náhľad <base>_t.<ext>.
 * $thumb = null → veľkú verziu aj náhľad vyrobí server cez GD; bez GD sa uloží originál a slúži aj ako náhľad.
 */
function upload_store_pair(array $full, ?array $thumb, string $subdir, string $base, bool $fromHttp = true): array
{
    if (!preg_match(UPLOAD_SUBDIR_RE, $subdir) || !preg_match(UPLOAD_BASE_RE, $base)) {
        throw new InvalidArgumentException('Neplatná cesta pre upload.');
    }
    $ext = upload_check($full);
    $tExt = $thumb !== null ? upload_check($thumb) : null;

    ensure_storage();
    if (!is_dir(upload_path($subdir)) && !mkdir(upload_path($subdir), 0775, true)) {
        throw new UploadException('Fotku sa nepodarilo uložiť, skús znova.');
    }

    if ($thumb !== null) {
        $fullRel = "$subdir/$base.$ext";
        $thumbRel = "$subdir/{$base}_t.$tExt";
        upload_move($full['tmp_name'], upload_path($fullRel), $fromHttp);
        upload_move($thumb['tmp_name'], upload_path($thumbRel), $fromHttp);
    } elseif (gd_available()) {
        [$sw, $sh] = getimagesize($full['tmp_name']); // rozmery bez dekódovania (upload_check už overil, že je to obrázok)
        gd_check_pixels($sw, $sh);
        @ini_set('memory_limit', '256M'); // dekódovaná 24 MP fotka zaberie ~100 MB
        $out = function_exists('imagewebp') ? 'webp' : 'jpg';
        $fullRel = "$subdir/$base.$out";
        $thumbRel = "$subdir/{$base}_t.$out";
        gd_resize($full['tmp_name'], upload_path($fullRel), IMAGE_FULL_MAX);
        gd_resize($full['tmp_name'], upload_path($thumbRel), IMAGE_THUMB_MAX);
    } else {
        $fullRel = $thumbRel = "$subdir/$base.$ext";
        upload_move($full['tmp_name'], upload_path($fullRel), $fromHttp);
    }
    [$w, $h] = getimagesize(upload_path($fullRel));
    return ['full' => $fullRel, 'thumb' => $thumbRel, 'w' => $w, 'h' => $h];
}

function upload_move(string $from, string $to, bool $fromHttp): void
{
    $ok = $fromHttp ? move_uploaded_file($from, $to) : copy($from, $to);
    if (!$ok) throw new UploadException('Fotku sa nepodarilo uložiť, skús znova.');
}

function gd_available(): bool
{
    return function_exists('imagecreatefromstring') && (function_exists('imagewebp') || function_exists('imagejpeg'));
}

function gd_check_pixels(int $w, int $h): void
{
    if ($w * $h > GD_MAX_PIXELS) throw new UploadException('Fotka má príliš vysoké rozlíšenie, zmenši ju prosím.');
}

function gd_resize(string $src, string $dest, int $max): void
{
    $img = @imagecreatefromstring((string)file_get_contents($src));
    if ($img === false) throw new UploadException('Fotku sa nepodarilo spracovať.');
    if (function_exists('exif_read_data')) {
        $exif = @exif_read_data($src);
        $rot = [3 => 180, 6 => -90, 8 => 90][$exif['Orientation'] ?? 1] ?? 0;
        if ($rot !== 0) $img = imagerotate($img, $rot, 0);
    }
    $w = imagesx($img);
    $h = imagesy($img);
    $scale = min(1, $max / max($w, $h));
    $nw = max(1, (int)round($w * $scale));
    $nh = max(1, (int)round($h * $scale));
    $out = imagecreatetruecolor($nw, $nh);
    imagealphablending($out, false);
    imagesavealpha($out, true);
    imagecopyresampled($out, $img, 0, 0, 0, 0, $nw, $nh, $w, $h);
    $ok = str_ends_with($dest, '.webp') ? imagewebp($out, $dest, 82) : imagejpeg($out, $dest, 85);
    if (!$ok) throw new UploadException('Fotku sa nepodarilo uložiť, skús znova.');
}

/** Vráti záznam z $_FILES, alebo null, ak pole chýba / nebol vybraný súbor. */
function upload_field(string $name): ?array
{
    $f = $_FILES[$name] ?? null;
    if (!is_array($f) || !isset($f['error']) || is_array($f['error']) || $f['error'] === UPLOAD_ERR_NO_FILE) return null;
    return $f;

function upload_delete(?string $rel): void
{

    if (!is_dir($dir)) return;
    foreach (glob("$dir/*") ?: [] as $f) @unlink($f);
```

```php
const LOGIN_LOCK_SECONDS = 900;

function auth_file(): string
{
    return data_dir() . '/auth.json';

/** Hash hesla; '' ak heslo nie je nastavené alebo je auth.json poškodený (vtedy sa nikto neprihlási). */
function auth_hash(): string
{
    $file = auth_file();
    if (!is_file($file)) return '';
    $data = json_decode((string)file_get_contents($file), true);
    $hash = is_array($data) ? ($data['hash'] ?? '') : '';
    if (!is_string($hash) || $hash === '') {
        error_log('data/auth.json je poškodený');
        return '';
    }
    return $hash;
}

/** Zapíše hash. $exclusive = true (install): len ak auth.json ešte neexistuje, inak vráti false. */
function auth_write_hash(string $hash, bool $exclusive = false): bool
{
    ensure_storage();
    $json = json_encode(['hash' => $hash, 'changed' => now_iso()], JSON_UNESCAPED_SLASHES | JSON_THROW_ON_ERROR);
    if ($exclusive) {
        $fh = @fopen(auth_file(), 'x');
        if ($fh === false) return false;
        $ok = fwrite($fh, $json) === strlen($json);
        fclose($fh);
        if (!$ok) {
            @unlink(auth_file());
            throw new RuntimeException('Nepodarilo sa uložiť heslo.');
        }
        return true;
    }
    $tmp = auth_file() . '.tmp-' . bin2hex(random_bytes(4));
    if (file_put_contents($tmp, $json) === false || !rename($tmp, auth_file())) {
        @unlink($tmp);
        throw new RuntimeException('Nepodarilo sa uložiť heslo.');
    }
    return true;
}

function auth_pw_version(): string

    $hash = auth_hash();

/* ---------- klient a rate-limit ---------- */

/**
 * IP klienta. Websupport má pred Apache nginx proxy: vtedy je REMOTE_ADDR súkromná/loopback adresa
 * a skutočnú adresu nesie X-Real-IP / X-Forwarded-For. Pri verejnej REMOTE_ADDR sa hlavičky ignorujú
 * (klient by si ich vedel podvrhnúť).
 */
function auth_client_ip(?array $server = null): string
{
    $s = $server ?? $_SERVER;
    $remote = (string)($s['REMOTE_ADDR'] ?? '');
    if (filter_var($remote, FILTER_VALIDATE_IP) === false) return $remote === '' ? 'cli' : $remote;
    if (filter_var($remote, FILTER_VALIDATE_IP, FILTER_FLAG_NO_PRIV_RANGE | FILTER_FLAG_NO_RES_RANGE) !== false) {
        return $remote;
    }
    $forwarded = explode(',', (string)($s['HTTP_X_FORWARDED_FOR'] ?? ''));
    foreach ([(string)($s['HTTP_X_REAL_IP'] ?? ''), $forwarded[0]] as $candidate) {
        $candidate = trim($candidate);
        if (filter_var($candidate, FILTER_VALIDATE_IP) !== false) return $candidate;
    }
    return $remote;
}

/** Kľúč klienta pre rate-limit: IPv4 celá adresa, IPv6 celá /64 sieť (jeden domov/zariadenie). */
function auth_client_key(?string $ip = null): string
{
    $ip ??= auth_client_ip();
    $bin = @inet_pton($ip);
    if ($bin !== false && strlen($bin) === 16) $ip = bin2hex(substr($bin, 0, 8)) . '::/64';
    return hash('sha256', $ip);
}

/** Vráti 'ok' | 'bad' | 'locked'. Pokus sa započíta ešte pred overením hesla (súbežné požiadavky nedostanú navyše). */
function auth_attempt(string $password, string $clientKey, ?int $now = null): string
{
    $now ??= time();
    $gate = auth_rate_register($clientKey, $now); // 'locked' | 'check' | 'last'
    if ($gate === 'locked') return 'locked';
    $hash = auth_hash();
    if ($hash !== '' && password_verify($password, $hash)) {
        auth_rate_success($clientKey);
        if (session_status() === PHP_SESSION_ACTIVE) session_regenerate_id(true);
        $_SESSION['admin'] = true;
        $_SESSION['pw'] = auth_pw_version();
        unset($_SESSION['csrf']); // nový CSRF token po prihlásení
        return 'ok';
    }
    return $gate === 'last' ? 'locked' : 'bad';
}

/** V jednom zamknutom kroku: skontroluje blokácie a započíta pokus. 'last' = týmto pokusom sa práve zablokovalo. */
function auth_rate_register(string $key, int $now): string
{
    return store_update('login-attempts', 'attempts', function (array &$all) use ($key, $now): string {
        $g = $all['*'] ?? ['times' => [], 'locked_until' => 0];
        $g['times'] = array_values(array_filter((array)($g['times'] ?? []), fn($t): bool => is_int($t) && $t > $now - LOGIN_LOCK_SECONDS));
        foreach ($all as $k => $a) {
            if ($k !== '*' && (($a['locked_until'] ?? 0) <= $now) && (($a['last'] ?? 0) < $now - LOGIN_LOCK_SECONDS)) unset($all[$k]);
        }
        $a = $all[$key] ?? ['fails' => 0, 'locked_until' => 0, 'last' => 0];
        if (($g['locked_until'] ?? 0) > $now || $a['locked_until'] > $now) {
            $all['*'] = $g;
            return 'locked';
        }
        if ($a['last'] < $now - LOGIN_LOCK_SECONDS) $a['fails'] = 0;
        $a['fails']++;
        $a['last'] = $now;
        $a['locked_until'] = 0;
        $g['times'][] = $now;
        $last = false;
        if ($a['fails'] >= LOGIN_MAX_FAILS) {
            $a['fails'] = 0;
            $a['locked_until'] = $now + LOGIN_LOCK_SECONDS;
            $last = true;
        }
        if (count($g['times']) >= LOGIN_GLOBAL_MAX) {
            $g['times'] = [];
            $g['locked_until'] = $now + LOGIN_LOCK_SECONDS;
            $last = true;
        }
        $all[$key] = $a;
        $all['*'] = $g;
        auth_rate_trim($all);
        return $last ? 'last' : 'check';
    }, true);
}

/** Úspešné prihlásenie: vynuluje klienta a jeho pokus sa nepočíta do globálneho stropu. */
function auth_rate_success(string $key): void
{
    store_update('login-attempts', 'attempts', function (array &$all) use ($key): void {
        unset($all[$key]);
        if (!empty($all['*']['times'])) array_pop($all['*']['times']);
    }, true);
}

/** Najviac LOGIN_MAX_ENTRIES klientov (ponechá najnovších) + globálny záznam '*'. */
function auth_rate_trim(array &$all): void
{
    $global = $all['*'] ?? null;
    unset($all['*']);
    if (count($all) > LOGIN_MAX_ENTRIES) {
        uasort($all, fn(array $a, array $b): int => ($b['last'] ?? 0) <=> ($a['last'] ?? 0));
        $all = array_slice($all, 0, LOGIN_MAX_ENTRIES, true);
    }
    if ($global !== null) $all['*'] = $global;
}

function auth_logout(): void
{
    auth_start_session();
    $_SESSION = [];
    $p = session_get_cookie_params();
    setcookie(session_name(), '', ['expires' => time() - 3600, 'path' => $p['path'], 'secure' => $p['secure'], 'httponly' => true, 'samesite' => 'Lax']);
    session_destroy();
}

}

{

    if (str_len($new) < PASSWORD_MIN) throw new ValidationException(['new' => 'Heslo musí mať aspoň 10 znakov.']);
    if ($new !== $new2) throw new ValidationException(['new2' => 'Nové heslá sa nezhodujú.']);
    auth_set_password($new);
}
```

```php
declare(strict_types=1);

/** Skopíruje ukážkové dáta a obrázky. Existujúce súbory nikdy neprepíše. */
function install_seed(string $seedDir): void
{
    ensure_storage();
    foreach (glob("$seedDir/data/*.json") ?: [] as $src) {
        $dest = data_dir() . '/' . basename($src);
        if (!is_file($dest)) copy($src, $dest);
    }
    $base = "$seedDir/uploads";
    if (!is_dir($base)) return;
    $it = new RecursiveIteratorIterator(new RecursiveDirectoryIterator($base, FilesystemIterator::SKIP_DOTS), RecursiveIteratorIterator::SELF_FIRST);
    foreach ($it as $item) {
        $rel = str_replace('\\', '/', substr($item->getPathname(), strlen($base) + 1));
        $dest = uploads_dir() . '/' . $rel;
        if ($item->isDir()) {
            if (!is_dir($dest)) mkdir($dest, 0775, true);
        } elseif (!is_file($dest)) {
            copy($item->getPathname(), $dest);
        }
    }
}
```

```php
<?php
declare(strict_types=1);

function redirect(string $to): never
{
    header('Location: ' . $to);
    exit;
}

function flash(string $msg, string $type = 'ok', ?string $link = null): void
{
    $_SESSION['flash'] = ['type' => $type, 'msg' => $msg, 'link' => $link];
}

function flash_html(): string
{
    $f = $_SESSION['flash'] ?? null;
    unset($_SESSION['flash']);
    if (!$f) return '';
    $link = $f['link'] ? ' <a href="' . e($f['link']) . '" target="_blank">Pozrieť na webe ↗</a>' : '';
    return '<div class="flash flash-' . e($f['type']) . '">' . e($f['msg']) . $link . '</div>';
}

function field_error(array $errors, string $key): string
{
    return isset($errors[$key]) ? '<em class="a-err">' . e($errors[$key]) . '</em>' : '';
}

/** Spoločná kontrola POST formulárov adminu. */
function admin_post_only(string $back): void
{
    if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
        http_response_code(405);
        exit('Nepovolená metóda.');
    }
    if (empty($_POST) && (int)($_SERVER['CONTENT_LENGTH'] ?? 0) > 0) {
        flash('Súbor je príliš veľký pre server. Skús menšiu fotku.', 'error');
        redirect($back);
    }
    if (!csrf_check($_POST['csrf'] ?? null)) {
        flash('Platnosť formulára vypršala, skús to znova.', 'error');
        redirect($back);
    }
}

function admin_header(string $title, bool $nav = true): void
{
    ?>
<!DOCTYPE html>

  <meta charset="UTF-8">

    <form method="post" action="logout.php"><?= csrf_field() ?><button class="a-link">Odhlásiť</button></form>
  </nav>
  <?php endif; ?>
</header>
<main class="a-main">
  <h1><?= e($title) ?></h1>
  <?= flash_html() ?>
<?php
}

function admin_footer(): void
{

</main>
<script src="admin.js"></script>

</html>
```

```js
/* Admin ALFA — potvrdzovanie mazania, zmenšovanie a nahrávanie fotiek. */
(function () {
  "use strict";

  /* ---- Mazanie na dve kliknutia (bez blokujúceho window.confirm) ---- */
  document.querySelectorAll("form[data-confirm]").forEach(function (form) {
    const btn = form.querySelector("button");
    const label = btn.textContent;
    let armed = false;
    form.addEventListener("submit", function (e) {
      if (armed) return;
      e.preventDefault();
      armed = true;
      btn.textContent = form.dataset.confirm;
      btn.classList.add("a-armed");
      setTimeout(function () {
        armed = false;
        btn.textContent = label;
        btn.classList.remove("a-armed");
      }, 4000);
    });
  });
```

```js
  /* ---- Zmenšenie fotky v prehliadači (veľká 1600 px + náhľad 480 px, WebP) ---- */
  const FULL_MAX = 1600, THUMB_MAX = 480, QUALITY = 0.82;
  const canDecode = "createImageBitmap" in window;
  const canSetFiles = "DataTransfer" in window;

  function decode(file) {
    return createImageBitmap(file, { imageOrientation: "from-image" }).catch(function () {
      return createImageBitmap(file); // staršie prehliadače bez options
    });
  }
  function toBlob(canvas, type) {
    return new Promise(function (resolve) { canvas.toBlob(resolve, type, QUALITY); });
  }
  async function draw(bmp, max, name) {
    const scale = Math.min(1, max / Math.max(bmp.width, bmp.height));
    const canvas = document.createElement("canvas");
    canvas.width = Math.max(1, Math.round(bmp.width * scale));
    canvas.height = Math.max(1, Math.round(bmp.height * scale));
    canvas.getContext("2d").drawImage(bmp, 0, 0, canvas.width, canvas.height);
    let blob = await toBlob(canvas, "image/webp");
    if (!blob || blob.type !== "image/webp") blob = await toBlob(canvas, "image/jpeg");
    if (!blob) throw new Error("Fotku sa nepodarilo spracovať.");
    return new File([blob], name + (blob.type === "image/webp" ? ".webp" : ".jpg"), { type: blob.type });
  }
  async function makePair(file) {
    const bmp = await decode(file);
    try {
      return { full: await draw(bmp, FULL_MAX, "full"), thumb: await draw(bmp, THUMB_MAX, "thumb") };
    } finally {
      if (bmp.close) bmp.close();
    }
  }
  function setFiles(input, files) {
    const dt = new DataTransfer();
    files.forEach(function (f) { dt.items.add(f); });
    input.files = dt.files;
  }

  document.querySelectorAll("input[type=file][data-resize]").forEach(function (input) {
    if (!canDecode || !canSetFiles) return; // bez podpory pošle originál, zmenší server
    const form = input.form;
    const fullIn = form.querySelector("input[name=image_full]");
    const thumbIn = form.querySelector("input[name=image_thumb]");
    const status = form.querySelector("[data-resize-status]");
    let busy = null;

    input.addEventListener("change", function () {
      setFiles(fullIn, []);
      setFiles(thumbIn, []);
      const file = input.files[0];
      if (!file) return;
      status.textContent = "Pripravujem fotku…";
      busy = makePair(file).then(function (pair) {
        setFiles(fullIn, [pair.full]);
        setFiles(thumbIn, [pair.thumb]);
        setFiles(input, []); // veľký originál neposielame
        status.textContent = "Fotka pripravená (" + Math.round(pair.full.size / 1024) + " KB).";
      }).catch(function () {
        status.textContent = "Fotku sa nepodarilo zmenšiť v prehliadači — odošle sa pôvodná (max 5 MB).";
      }).finally(function () { busy = null; });
    });

    form.addEventListener("submit", function (e) {
      if (!busy) return;
      e.preventDefault();
      status.textContent = "Chvíľu počkaj, fotka sa ešte pripravuje…";
      busy.then(function () { form.requestSubmit(); });
    });
  });
```

```js
  /* ---- Hromadné nahrávanie do albumu (po jednej fotke, s priebehom) ---- */
  document.querySelectorAll("[data-album-upload]").forEach(function (box) {
    const input = box.querySelector("input[type=file]");
    const status = box.querySelector("[data-upload-status]");
    const failsEl = box.querySelector("[data-upload-fails]");
    const csrf = box.querySelector("input[name=csrf]").value;

    input.addEventListener("change", function () {
      const files = Array.from(input.files);
      input.value = "";
      if (files.length) run(files);
    });

    async function uploadOne(file) {
      const fd = new FormData();
      fd.append("csrf", csrf);
      fd.append("album", box.dataset.album);
      let pair = null;
      if (canDecode) {
        try { pair = await makePair(file); } catch (e) { pair = null; }
      }
      if (pair) {
        fd.append("full", pair.full);
        fd.append("thumb", pair.thumb);
      } else {
        fd.append("full", file); // zmenší server
      }
      let res;
      try {
        res = await fetch(box.dataset.endpoint, { method: "POST", body: fd, credentials: "same-origin" });
      } catch (e) {
        throw new Error("Chyba pripojenia.");
      }
      let data = null;
      try { data = await res.json(); } catch (e) { data = null; }
      if (!res.ok || !data || !data.ok) {
        throw new Error((data && data.error) || "Nahrávanie zlyhalo (" + res.status + ").");
      }
    }

    async function run(files) {
      failsEl.innerHTML = "";
      input.disabled = true;
      const failed = [];
      for (let i = 0; i < files.length; i++) {
        status.textContent = "Nahrávam " + (i + 1) + " / " + files.length + "…";
        try { await uploadOne(files[i]); }
        catch (err) { failed.push({ file: files[i], error: err.message }); }
      }
      input.disabled = false;
      if (!failed.length) {
        status.textContent = "Hotovo — nahraných " + files.length + ".";
        location.reload();
        return;
      }
      status.textContent = "Nahraných " + (files.length - failed.length) + " z " + files.length + ". Tieto sa nepodarili:";
      failed.forEach(function (f) {
        const li = document.createElement("li");
        li.textContent = f.file.name + " — " + f.error;
        failsEl.appendChild(li);
      });
      const li = document.createElement("li");
      const retry = document.createElement("button");
      retry.type = "button";
      retry.className = "a-btn";
      retry.textContent = "Skúsiť znova neúspešné";
      retry.addEventListener("click", function () { run(failed.map(function (f) { return f.file; })); });
      const reload = document.createElement("button");
      reload.type = "button";
      reload.className = "a-btn";
      reload.textContent = "Zobraziť nahrané";
      reload.style.marginLeft = ".5rem";
      reload.addEventListener("click", function () { location.reload(); });
      li.appendChild(retry);
      li.appendChild(reload);
      failsEl.appendChild(li);
    }
  });
```
