## Nálezy a ako ich opraviť v pláne (`docs/superpowers/plans/2026-10-12-cms-admin.md`)

1. **high — Task 2 `text_to_html`:** `nl2br` necháva `\n` za `<br>` → test čaká `Prvý<br>riadok`.
   Oprava: `str_replace("\n", '<br>', $html)` namiesto `nl2br`.
2. **high — install.php únos:** ktokoľvek prvý nastaví heslo. Oprava (už v spec §5): `install-token.php`
   (mimo gitu, generuje `tools/new-install-token.php`, token čítať cez `file_get_contents`+regex, nie `require`),
   `install.php?token=…` musí sedieť (`hash_equals`), `data/auth.json` vytvoriť cez `fopen(…, 'x')`,
   po úspechu token zmazať. Heslo presunúť z `config.php` do `data/auth.json` (rieši aj opcache, nález 10).
   Zabudnuté heslo = zmazať `data/auth.json` + nový token. `config.php`/`config.sample.php`/`config_save` zrušiť.
   Testy: parsovanie tokenu, výhradné vytvorenie auth.json (2. pokus false).
3. **medium — rate-limit:** (a) race — pokus započítať pred `password_verify` v jednom `store_update`;
   (b) IPv6 kľúč po /64 (`auth_client_key(?string $ip)`); (c)+(globál) strop 50 zlyhaní / 15 min pre všetkých;
   (d) max 500 záznamov, bez záloh. `store_update(..., bool $volatile = false)`: volatile = bez zálohy,
   poškodený súbor = []. Na 5. pokuse sa heslo ešte overí (správne → ok). Testy: globálny strop, IPv6 /64,
   poškodený login-attempts = prázdny.
4. **medium — HTTPS:** `.htaccess` presmerovanie pre `^(admin/|install\.php)` ak `%{HTTPS}!=on` a
   `X-Forwarded-Proto!=https` a host nie je localhost; to isté v PHP (`request_is_https()`), cookie `secure`
   podľa `request_is_https()`.
5. **medium — StoreException mimo try:** `post-edit.php` (`post_get`), `album.php` (`album_get`),
   `api/upload.php` (`album_get` → JSON 500), login (`auth_locked` → volatile čítanie).
6. **medium — GD pamäť:** pred dekódovaním `getimagesize`; nad 25 MP `UploadException('Fotka má príliš
   vysoké rozlíšenie, zmenši ju prosím.')`; `@ini_set('memory_limit','256M')`. Funkcia `gd_check_pixels(w,h)` + test.
7. **medium — .htaccess robustnosť:** zrušiť `uploads/.htaccess` (RemoveHandler/Options môžu dať 500);
   do koreňového `.htaccess` `RewriteRule ^data(/|$) - [F,L]`, `^uploads/.*\.(php\d?|phtml|phar)$ - [F,L]`,
   `tools`, `_zaloha`, `install-token\.php`. `data/.htaccess` ponechať. NASADENIE: kontroly 403/obrázky,
   čo pri 500 (zakomentovať `Options`).
8. **medium — nasadenie:** NASADENIE §2 — súbory z vetvy `cms-admin`, merge do `main` až po vypnutí Pages.
   Task 14 aktualizuje aj `README.md` (dnes spomína `.html` a `site/`).
9. **low — session handler:** `ini_set('session.save_handler','files')` pred `session_save_path`.
10. **low — config tmp/opcache:** vyriešené presunom hesla do `data/auth.json` (nález 2).
11. **low — post-edit null:** `post_update` vráti null (zmazané v inej karte) → flash „Aktualita sa nenašla.“,
    zmazať nahratú fotku.
12. **low — regex `$`:** pridať modifikátor `D` do `valid_id` a `UPLOAD_*_RE`; test `valid_id("p_abcdef\n")` false.
13. **low — dizajn:** demo pásik len pri `SITE_DEMO` (`inc/site.php`); preniesť CTA pás do `aktuality.php`;
    CSS `.post > a{display:block}` + `.post-img{display:block}`.
14. **low — limity/mbstring:** hláška pri `UPLOAD_ERR_INI_SIZE` s `ini_get('upload_max_filesize')`;
    `mbstring` do požiadaviek; `install_requirements()` v install.php; `mb_internal_encoding` cez `function_exists`.
15. **low — relácie:** do session `pw` (hash verzie hesla), `auth_is_logged_in` porovná; po zmene hesla
    aktualizovať v aktuálnej relácii; po prihlásení `unset($_SESSION['csrf'])`. Testy.
16. **low — JS UX:** po zmenšení neodstraňovať súbor z viditeľného inputu, ale mu zobrať `name`
    (a vrátiť pri novom výbere); náhľad `<img>`; `beforeunload` počas hromadného nahrávania.
17. **low — overovacie kroky:** `php -S … >/dev/null 2>&1 & PID=$!; sleep 1; …; kill $PID` v jednom bloku;
    Task 1: overiť `php --ini`/`php -m` v novom shelli, inak `export PHPRC="$PHPDIR"` (+ `setx PHPRC`).

Po úprave plánu prepočítať počty testov v „Expected“ (Task 7 Step 5, Task 14 Step 3).

## Doplnok 2026-10-14 — hosting = Websupport (spec už upravený)

Pri oprave plánu zapracovať aj:
18. **Websupport / PHP:** v pláne a `NASADENIE.md` uviesť PHP 8.3+ (8.1 je na Websupporte za príplatok);
    `NASADENIE.md` písať konkrétne pre Websupport (WebAdmin → PHP verzia, SSL, SFTP).
19. **Install token bez SSH:** `tools/new-install-token.php` sa spúšťa lokálne, `install-token.php` sa nahrá
    cez SFTP (trvalé SSH na Websupporte nie je). Upraviť Task s tokenom + NASADENIE.
20. **IP za nginx proxy:** `auth_client_ip()` — `REMOTE_ADDR`, a len ak je súkromná/loopback
    (`filter_var` bez `FILTER_FLAG_NO_PRIV_RANGE|NO_RES_RANGE`), tak `X-Real-IP` / prvá z `X-Forwarded-For`
    (validovaná `filter_var(FILTER_VALIDATE_IP)`). `install.php` zobrazí zistenú IP. Testy: verejná
    REMOTE_ADDR ignoruje hlavičky; 127.0.0.1 + X-Real-IP → X-Real-IP; neplatná hlavička → REMOTE_ADDR.
